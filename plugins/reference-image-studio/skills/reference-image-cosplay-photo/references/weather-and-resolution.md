# 按需：天气材质与高清增强

## 天气改变的是物理状态

依据本次服装的材料及用户要求表现状态，不把所有服装都设为吸水或防水。若已确认的材质与请求明显冲突，说明将作为本次材质变体，关键冲突再核实；不改写常规设计。

需要明显浸湿时，不能仅添加雨线、地面积水和布面水珠：

- 吸水布料会有颜色加深、挺度下降、较长的重力褶皱，以及外层贴合下方衣层的变化；裙摆、褶边、蝴蝶结和拖尾的蓬松体积可能减小。保留原部件与长度，不把“下垂”画成斗篷加长、裙子改款。
- 透光取决于材料、衬里、重叠层与光照。半透明不等于默认透出皮肤或内衣，不能仅为加强湿感增加露肤或改变覆盖范围。
- 假发可呈更重、更暗、较窄的黏合发束，湿发尾凝聚和滴水；保留编发、发饰与辨识性发束。不要只给蓬松干发撒亮点。
- 干净雨水的浸湿深浅是连续织物色与柔和过渡，不是泥污、霉斑或旧化纹理。若未指定泥水，避免用黑褐色斑点表达湿透。
- 区分吸水后的低广反光与防水表面的挂珠亮膜；金属、树脂与织物可以有不同的挂水状态。风的方向、发束、布料与雨线也应相容。

目视核对是否真的出现用户要求的材质变化。没有落实时直接报告偏差，不能把提示词中的“饱水”当作结果证据。一次纠偏聚焦已观察的问题，避免不断叠加相互冲突的形容词。

## 分辨率与增强

用户要求尺寸时先查当前工具 schema 或官方能力。内置生成器、第三方参考图生成、专用超分、插值放大是不同路径；不能把一个工具的参数能力套到另一个工具，也不能把提示词写“4K”当作已设置4K输出。

- **原生生成**：有尺寸参数就按实际支持选择；没有则说明不能保证指定像素，生成后读取实际宽高。聊天预览可能缩小，交付可访问的原图。
- **生成式高清增强**：按用户指定，以选定照片作唯一主要底图，请求保留全幅、面部、姿势、造型、材质与背景，仅恢复细节。不要顺带修眼色、改天气或重做服装。新增参考可能引发改款，只有有必要且符合用户意图时加入。说明可能重绘微细节，不能称为像素级保真超分。
- **专用超分或插值**：仅环境实际提供时使用并按真实方法命名。插值增加像素不等于恢复真实细节；用户要求某模型时不擅自换成其他路径。

记录输入与输出尺寸、方法和参数。比较整幅与面部、金边、饰品、布料纹理等关键区域，检查裁切、塑料锐化、虚构纹样和设计漂移。输出另存，不覆盖用户选定的底图。达到期望像素但身份或材质退化时如实报告，不以尺寸增大替代效果验收。
