# 参考驱动的真人 cosplay 摄影

生成真人模特穿着角色 cosplay 服装的照片。服装来源、模特身份和本次摄影意图各司其职：设计参考决定穿什么，模特参考决定面部身份，用户描述或构图参考决定拍什么。默认直接完成已明确的生成请求，不把人台设计方案确认作为照片生成的前置步骤。

## 选择入口与依据

先阅读工作区已有的 `AGENTS.md`、`REFERENCE_WORKSPACE.md`（如有）、`references/INDEX.md` 及本次相关设定，再实际查看会用到的原图。没有索引时直接使用用户本次提供的材料，不强制初始化；沿用项目目录，不将其他项目的角色或模特带入本次。

- **已有 cosplay 设计图**：按用户选定或已确认的服装版本生成。完整造型、部件特写和无斗篷等拆除展示分别使用；不能因为结构图移除了假发、头纱或外衣，就把完整穿着中的相应组件删掉。原角色图补充设计图未覆盖的已知细节，不无声推翻已确认的 cosplay 转译。
- **只有角色原画、设定图**：可以直接转译为真人 cosplay 摄影，无需先生成服装板或人台图。保留轮廓、色块、长度、层次、标志性饰件和发型；将绘画表现转换为布料、假发纤维、金属涂层、树脂等可见质感，不把拟定材质和隐藏工艺称为原作事实。
- **只有明确文字设定**：足够具体时可据此生成，说明未做图像核验；只有角色名且没有可用设计依据时，请求最关键的原画或服装参考，不能凭记忆宣称严格还原。
- 用户实际要先设计服装、确认材质结构或出人台正侧背图时，转到 [reference-image-cosplay](../reference-image-cosplay/SKILL.md)。不要为了照片任务自动扩大为服装设计项目。

按部位记录来源和适用范围，区分完整造型、临时状态、拆除配件、材质类比和姿势参考。当前视角被遮挡的部件不视为不存在；未显示的背面只作本画面必要的克制推断，不添加无依据的扣件或装饰。只澄清影响当前照片的关键版本冲突，不为无关隐藏结构反复索图。

## 模特与参考职责

用户可提供模特照片，也可以不提供：

- 有模特参考时，保留面部轮廓、五官比例、可见特征及用户要求的妆面。四宫格、多角度照片按同一人面部参考处理，不生成拼图。除非用户明确指定，不带入模特参考的发型、衣服、背景或姿势；角色假发与配饰仍以造型依据为准。
- 无模特参考时，自行生成符合用户描述的模特，不把索要模特照片作为前置条件，也不宣称生成脸对应某个现实人物。只有身份特征对任务确实关键又无法推断时才询问。
- 多张照片不能确定是否为同一人，或不同人分别承担面部、身形、姿势用途时，先厘清会改变身份的歧义。不要自动混合不同人的面部。
- 既有生成照片仅在用户指定的范围内作连续性参考。用户要求“重新生成、不要改这张”时，从原始身份和服装依据开始，不将旧成图作编辑底图；若确需将旧照片作辅助参考，先确认这符合用户意图。

在提示词与记录中按实际输入顺序标注每张图的职责。不要把“文件路径写进提示词”当作已传图；数量受限时优先保留关键面部和完整服装参考，说明被省略的局部依据。

## 摄影与服装转译

提取用户指定的场景、动作、表情、构图、时段、天气和镜头效果。未指定的低影响细节可合理选择；全身入镜并非所有任务的默认要求，但一旦指定，须包含头饰、发尾、垂饰与双脚并留出边缘空间。按新姿势调整透视、遮挡与衣料受力，不能将设计图站姿直接复制成所有照片。

- 服装、假发、配饰、鞋袜分别核对，按当前视角检查应露出的组件。近似的心形、泪滴、菱形等标志不能互换，装饰金带不能被误读为服装开口。
- 将角色眼色转换为真实有色隐形眼镜：自然虹膜纹理、暗色瞳孔、正常眼白及环境反光。除非用户指定特殊效果，不将动漫高光、心形亮点或变身光效照搬成发光眼睛。
- 自然皮肤、妆面、假发纤维、织物纹理与受力褶皱形成真实感；避免所有材料都变成塑料。布料透光、反光与重力应符合本次材质和光照，不为了“真实”擅自改款。
- 镜头焦段、光圈和景深是视觉意图，不等于真实相机 EXIF。主体细节与背景虚化要相容，避免夸张广角比例或用全画面锐化破坏焦外层次。

有雨水、浸湿、风或其他材质状态，以及用户要求高清放大时，按需读取 [天气材质与高清增强](references/weather-and-resolution.md)。普通摄影无需加载该文件。

## 执行、纠偏与交付

建立 `generations/<唯一批次>/` 或遵循项目现有目录，保存实际 `prompt.txt` 与 `NOTES.md`：用户要求、来源路径与职责、服装版本、是否指定模特、创作选择、允许推断、实际传图、模型与参数、输出和检查结果。参考原件不覆盖；生成脸、湿布状态或本次材质推断不自动进入标准索引。

使用环境可用的图片能力，并遵循相应图像工具 skill。尊重用户指定的工具和模型，调用前查当前支持的参考数量、比例和尺寸；名称不明确时只核实关键歧义。未指定时选择可用且适合参考一致性的工具，不把某供应商、固定模型、分辨率或密钥写成技能前提。工具不可用时保存准备材料并明确未完成出图，不将提示词当作图片交付。

实际查看整图和影响任务的细节：

- 面部是否延续参考，是否发生明显美颜或身份漂移；无面部参考时是否符合用户描述。
- 服装版本、轮廓与层次是否一致，应露配件、假发、美瞳、鞋袜是否遗漏或误变；遮挡与实际缺件分开判断。
- 手指、肢体、布料穿插、饰件连接和姿势是否合理，构图与天气材质是否落实；是否误带入人台、参考背景、文字或多视图排版。
- 不只检查改动处，也检查面部、完整造型和无关区域是否被误改。无法目视查看时如实说明，不宣称核验通过。

生成请求内的质量纠偏可直接执行，不重复要求独立修图计划确认。新增设计决定或超出授权的内容先澄清。连续两次纠偏仍出现同类错误时停止自动重试，保留最接近结果并说明未达到之处；用户预算或次数优先。用户提出独立的局部修复任务时，使用 [reference-image-repair](../reference-image-repair/SKILL.md) 的对应流程。

交付实际预览或可用文件链接，简述结果与重要偏差，报告实际像素而非只说“高清”。项目内使用的结果须保存回项目；只有用户明确认可相应范围并请求维护参考时才更新共享索引，不能把照片或用户对整体效果的称赞自动升级成设计定稿。
