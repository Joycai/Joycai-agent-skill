# 参考图创作工作约定

本工作区用于基于可信参考图与文字设定修正图片，以及从文字或草图生成新图片。

- 开始分析、生成或修正前，先阅读 `references/INDEX.md`，再实际查看本次相关参考原图、草图或待修图，不仅依赖文字摘要或会话记忆。仅有明确文字设定时可据此生成，不强制索要图片。
- 用户对参考用途和结构的明确说明是设定依据。按部位选择参考，根据目标透视、姿势、遮挡和光照调整；保留未要求改变的构图、表情与画风。
- 区分完整造型、临时阶段、拆除配件和跨对象局部类比。不能因某图未显示而删除其他标准确认存在的部件。
- 区分用户确认、实际可见和未知推断。不把隐藏结构或生成图补出的细节记为已确认设定；有影响当前修正的真实冲突时记录并核实。
- `references/` 原件不可覆盖或修改。待修原图、输出和辅助示意分开保存；生成结果须经用户明确确认其适用范围，才可作为相应范围的依据。
- 每次修正记录参考、提示词、结果和目视检查情况。既检查修改是否正确，也检查无关区域是否被误改。
- 生成新图片时，文字或草图决定本次构图意图，可信标准决定设计细节。草图省略不视为删除设定；生成结果和自由发挥不自动进入标准参考。

- 独立的成图修复任务默认先列出有依据的具体修改计划，等待用户确认或调整后再动手；已批准范围内的纠偏不重复确认，用户明确要求直接执行时遵从。生成任务内为满足原请求的纠偏、纯参考信息更新不需要另走修图计划确认。
