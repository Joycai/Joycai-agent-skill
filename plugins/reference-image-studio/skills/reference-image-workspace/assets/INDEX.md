## 参考登记

每张参考登记：编号、原图相对链接、来源、视角、状态、主要用途、适用范围、不适用范围。区分完整状态、临时状态、结构展示和跨对象局部类比。

## 用户明确确认的设定

收录用户说明及其适用范围，注明日期或来源。不要将图像推断填入此节。

## 可见形态与绘制要求

结合原图描述轮廓、体积、边缘、颜色关系和遮挡；按目标角度调整。使用类别名称会误导时，优先描述如何画。

## 待确认与冲突

记录尚无依据的隐藏细节，以及不能由视角、光照、遮挡或简化解释的冲突。

## 已替代或弃用的依据

记录被替代的说明与原因、旧示意的路径及使用限制。生成图不自动成为标准。
