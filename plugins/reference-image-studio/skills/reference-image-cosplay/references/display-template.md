# 人台展示模板

拟定方案和出图清单时读取。模板固定展示内容与一致性，不强制单图容纳全部内容；用户指定的输出范围、比例和背景优先。

## 完整造型主展示板

默认包含正面、侧面、背面，展示同一套完整穿戴的服装、假发及设定中存在的配饰、鞋袜。不为凑全套添加原设计没有的部件。

- 使用同一个比例适当、表面中性的无五官人台。需要支撑假发、耳饰时保留对应的头部和耳部结构，不生成人脸或真人模特。
- 使用自然中性站姿，手臂适当离开躯干，不遮住腰侧细节。保证全身轮廓和配件完整，不裁掉头饰、鞋、裙摆和背后垂饰。
- 正面与背面正对机位，侧面接近 90°；避免用三分之四视角代替侧面。默认选信息更充分的一侧；左右设计显著不同时在方案中加入另一侧。
- 用“穿戴者左侧／右侧”定义方向，不能按画面左右猜测。人台比例、主体显示尺度、镜头高度、背景与光线在各视图间一致。
- 默认浅中性背景、柔和棚拍光线、少量接触阴影，背景应与服装边缘形成足够区分。避免广角透视、戏剧性光影及道具遮挡设计。
- 三视图可同板横排，也可按分辨率需要独立成图；先保证细节和轮廓可辨认，不为固定横版强行缩小主体。

标题、视图标签及部件编号保持简短并核对文字。无法可靠渲染标签时，可在交付说明中建立对应关系，不能让错误标注影响左右和部件判断。

## 细节展示板

挑选“全身图无法辨认、但对设计还原有价值”的部位，不固定数量，不硬凑特写。常见内容包括耳环、发饰、胸口纹样、腰部挂饰、手套边缘、背部蝴蝶结及其尾带。

- 每个特写标明部位或编号，并保留足够邻近区域，说明其穿戴位置、朝向和连接关系。
- 特写是同一件服装的局部，不另行设计新纹样、配色、扣件或材料。只放大已有或获准补全的信息；模糊参考放大后仍不确定的内容不能冒充已知细节。
- 默认展示佩戴状态。若独立配件图更能说明结构，在方案中列出，且不能把拆下后的状态混入完整造型。
- 特写多时独立成页；不要把小格堆满主展示板导致三视图不可读。

## 可选分层模式

| 模式 | 输出范围 |
| --- | --- |
| 完整造型 | 默认主展示板与必要特写 |
| 完整造型＋分层补充 | 完整造型之外，移除明确指定的外层并补充必要角度 |
| 仅指定内层 | 只输出指定内层与用户选择保留的部件，无需附带完整造型 |

分层不是自动追加项。方案记录每个状态的“保留／移除”部件，以及正、侧、背中哪些角度能说明结构；不强制每个内层都重复全部角度。保留同一人台和比例，方便对照。

例如内层为 leotard、外穿裙装：

- 先确认连体结构来源，区分参考可见部分和裙下未知部分。裙装遮挡不能作为推断裤口、背部、接缝或开合方式的证据。
- 列出移除裙装后是否保留腰饰、假发、鞋袜及其他部件，避免模型随机增减。
- 选择能解释领口、侧腰、背部或下摆结构的视图；未知但必须展示的部分，先补充依据或确认具体补全方案。
- 内层图与完整造型中露出的领口、肩带、袖口、腰侧等必须对应；脱去外层不会改变内搭的材料、配色与连接方式。

## 方案中的出图清单格式

可按实际任务调整，未选中的可选项不加入执行范围：

| 编号 | 内容 | 穿戴状态／角度 | 依据与待确认事项 |
| --- | --- | --- | --- |
| A | 完整造型主板 | 正面、穿戴者左侧、背面 | 记录各角度来源及背面是否需补全 |
| B | 细节板 | 已选定的饰品或结构特写 | 每个局部指向对应来源及主图部位 |
| C（可选） | 内层展示 | 明确移除、保留部件及必要角度 | 区分可见结构与获准推断 |

在清单中写明合板或独立成图、预计图片数量及工具分辨率限制。需要增加页面或改变范围时先更新方案，不在生成中无声扩大任务。
