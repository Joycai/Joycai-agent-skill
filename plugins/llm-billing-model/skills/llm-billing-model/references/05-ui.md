# 05 · 界面

两个面：**计费组编辑器**（配置）与**用量页**（结果）。原则：主次分明，安静——不收的费不出现，没配的东西不占位。

## 计费组

### 列表行

`名称 + N 个模型` | 价格标签（每种模式同一格式）| 编辑 | 删除。价格标签：

| 模式 | 标签 |
| --- | --- |
| token | `输入 $0.0750/M` `缓存 $0.0187/M` `输出 $0.3000/M`（缓存未配时以斜体显示继承的输入价） |
| request | `请求 $0.0400/Req` |
| spec | `按张 · 6 档 · $0.04–0.08`（档数 = 有价的行；区间跨所有行）· 没兜底行时追加 `其他规格按 0 计` · 收输入费时追加 `输入图 $0.01/张 · 首 1 张免费` |

摘要一行版（列表、下拉、卡片共用）：`按 token · 0.30 / 0.03 / 2.50`、`按次 · $0.0400/次`、`按秒 · 4 档 · $0.10–0.50`。
价格摘要里剪尾零到至少两位（`0.5000 → 0.50`，`0.125` 保留），表格里固定四位。悬浮显示整张档位表，一行一档，末尾「其他规格」与「输入图」。

### 编辑器

- 模式用三段分段控件；切换只换下面的字段区，**不清空**别的模式的值。
- token：三个价，缓存价占位符写「留空 = 同输入价」。
- spec：
  1. 单位 chip（张 / 秒 / 条）+ 一句「怎么数」的说明（按张：响应里的图片张数；按秒：请求的时长，完成后按实际结算；按条：每次一条）。
  2. 档位表：每行 `尺寸 ▾ · 质量 ▾ · 时长 ▾ · 单价`，三个条件下拉可留空；下拉的词汇 = 各模型家族参数表 ∪ 协议参数表的并集（自动收集，**归一化后**）
     + 自由输入（中转自己拼的值）——**这是菜单，不是校验**。
  3. 校验只拦真错误：某行没填价 → 该行标红、禁保存；两行条件相同 → 点名两行号、禁保存。空表允许（组按 0 计，用量页会提示）。
  4. 输入图一行：一条发丝线下 `每张单价` + `每次免费张数`，三种单位都在（按秒 / 按条时副题换成「首帧 / 尾帧 / 参考图」）；
     单价非法标红。不填时，摘要、标签、悬浮表、用量页**都不出现「输入」二字**。
- request：一个价 + 那句提示之下，**同一个**输入图行部件（无档位表的删除列留白，单价框与请求字段右缘对齐）。
  摘要尾巴、卡片标签、用量页规格格「输入 2 张」、展开处「单价（= 请求单价）| 输出金额 | 输入图 | 输入金额」——按次行 = 规格行减去「规格」格。
- 手机：全屏编辑页，同一字段顺序。

## 用量页

### 汇总卡

预估成本（大字）+ 范围内请求数 | 输入 token | 缓存输入 | 输出 token（各自身份色的小圆点 + 进度条）| 缓存命中率
（`cache / (input + cache)`；范围内没有 prompt token 时显示空而不是 0%——「一次都没问缓存」不是「总是未命中」）。

### 按计费组统计（分组条）

- 每组一行：名称 | 8px 分段条 | 金额 | 数量列。条长 = 该组占范围总额的比例；条内分段按成本部分：
  输入 / 缓存 / 输出用三种 token 身份色，**按次 + 按规格 + 输入图 + 上游报价共用一个中性色**——都是买输出而不是买 token 的钱，靠 tooltip 区分。
- tooltip：百分比 + 每个非零部分一行（`输入 Token: $…`、`请求: $…`、`按规格: $…`、`输入图: $…`、`上游报价: $…`）。
- 数量列：token 组显示请求数；按规格组显示单位数 + 请求数（`38 张 · 12 次`、`126 秒 · 8 次`）。
- **未覆盖提示**：组内有 `matched = false` 的行时，条下一行「N 次请求未匹配任何档位，按 0 计」+ 「去补档位」按钮直达编辑器。
  有上游报价的行不计入。
- 按金额降序；已删除的组不显示（它的行仍计入总额）。

### 明细表

桌面列：`模型 | 明细 | 规格 | 时间 | 成本 | ▾`；平板：模型名一行，第二行 `明细 · 规格 · 时间`，右侧成本；手机：第二行 `规格 · 时间`。

- **模型**：类型色板（图像 / 视频 / 对话的字形 + 淡色底）+ 名称；`[渠道]` 前缀提成徽标，让名称对齐。
- **明细**：token 行 = 三个带色点的缩写数（`6.4K · 506 · 1.1K`，缓存为 0 时不出现那一枚），精确值在 tooltip；
  按次行 = `N 次`；按规格行 = `2 张` / `8 秒` / `1 条`。
- **规格**：`1K · low · 输入 1 张`——规格标签 + 收了输入费时的张数（次要色）；其它模式 `—`（outline 色）。
  未覆盖的行**照常写全规格**：它正是用户该抄进表的那一行。
- **成本**：mono 四位小数，右对齐；**0 用 outline 色**（免费的行也是行，但满格对比的一列 `$0.0000` 会淹掉真花钱的）。
  有上游报价的行**不带任何标记**（无字形、无副标、无颜色）：最可信的数字不能长得像可疑的那个，部分行带字形会打断右对齐的扫读；
  桌面 / 平板加两行 tooltip `上游报价: $… / 档位估算: $…`，手机不加。
- 日期分隔行：`今天 · 7 条` + 当日合计——**只有整天在范围内才显示合计**。
- 分页 Load More，底部状态行「已加载 100 / 总 1 234」。

### 展开网格

点行展开一个 mono 标签 / 值网格，两格一行，`wide` 条目独占一行；手机单列。条目顺序：

1. 有上游报价时**第一对**：`上游报价 $0.0700`（唯一全色金额）| `档位估算 $0.0600`（outline）。
   凡是档位表**算出来**的值（估算、单价、输出金额、输入金额）都退为 outline；请求**事实**（请求数、规格、输入图张数、token 数）照旧。
   不写「表过期」的句子、不用警示色——不一致是常态（`auto` 由模型定档），退色的一对就是全部信号；相等时几何相同；估算永不隐藏（默认 token 组下就是 `$0.0000`）。
2. `请求数`。
3. token 行：`输入 / 缓存输入 / 输出 token` 精确值。
4. 按规格行：`规格 | 单价`。
5. 组收输入费时（`D2c`）：`输出金额`、`输入图 3 张 · 1 张免费`（wide）、`输入金额 2 × $0.0200 = $0.0400`（wide；全免时 outline）。
   一张没交付的行：写 `3 张`，不写「免费」——没收是因为失败，不是因为免。
6. 尾部：「清除该模型记录」按钮（危险文字按钮）。

### 响应式

三种表单共用同一个条目列表，只是折法不同；390 / 834 / 1440 三档各有截图，溢出用测试抓（输入金额的算式在平板半格放不下 → wide）。
